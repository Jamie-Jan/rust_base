# rust_base

## 所有权
### 栈和堆
```rust
// 栈与堆: 是计算机内存中管理数据的空间;
/*
    - 当数据在rust中产生，会存储到栈与堆中:
        - 栈: 数据是通过FILO队列来存储数据，用于存储不可变数据，先进后出的方式存取数据;
        - 堆: 堆相当于内存中一个非常广泛的空间，数据在里面通过标记来存储数据，
            而且存储的数据是可变的，在运行时向内存分配器向内存申请空间来存储数据;
            
    - 当数据离开作用域以后，rust会自动释放已产生的数据;
*/
```

### 移动与克隆
```rust
/*
    - 移动: rust将 “栈” 上的数据，复制一份到另一个变量中; 而堆上的数据并没有复制;
        - 为了保证数据安全，原来的变量就会被标记为无效;
    - 克隆: rust将 “堆” 上的数据，复制一份到另一个变量中; 使用clone方法来复制一份新的数据;
    
    - 函数的引用与返回值（函数获取所有权）
        - 堆数据: String, 可变字符串存放在堆上，当做参数传递给函数的时候，会将值移动到函数中使用;
        - 栈数据: 整型，通过copy的方式传递给函数，copy前的值还是允许使用;
*/
```

### 引用与借用
```rust
/*
    - 引用: 
        - question: 在程序执行过程中，函数外定义的变量，若直接传递给函数，函数则会得到值的所有权，别的地方就不可以使用;
        - answer: 为了解决该问题，rust中使用了引用，让值传递到函数中，不获取值的所有权，使其既能在函数中使用，也能在别的地方使用;
        - summary: 传递某个值给函数时，只想使用值，但并不想要值的所有权，就通过引用来传递给函数;
        - how: 使用 &变量名 指定引用;
        - attention: 引用是不可变的，传递给函数的值是不可修改的; 必须要申明为可变引用才允许修改;
            - 1）可变引用: &mut
            - 2）在同一时间，只能有一个可变引用，避免数据竞争;
                - 在别的语言中，一个可变引用可以被多个地方引用，当内存释放时，引用的位置就会报错, 在rust中，在编译时就会避免这种问题;
            - 3）在函数中，若产生的数据，返回引用的值给调用者会报错，因为函数在执行结束后会销毁产生数据的内存;
                - 解决: 可以返回函数中数据的所有权，这样就不会被销毁;避免报错;
                
    - 借用:
        - 借用是创建引用的过程，在作用域中临时有效，当作用域结束后，该借用的值则会被销毁;
        
    - Errors:
        - 悬垂引用错误: 当函数中返回局部变量的引用时，该变量会在函数执行结束后被销毁，会导致引用悬垂引用问题而报错;
*/ 
```


### Slice切片
```rust
/*
    slice切片: 对一组序列集合值的部分或全部值的引用;
        - 字符串切片:
            - 字符串字面量与字符串切片: 
                - 字符串字面量本质上是一个字符串切片，但是一个二进制固定位置的切片，是不可变的;
                - &String: 字符串字面量，可用于函数接收参数;
                - &str: 一般用于函数的返回值，既能是字符串字面量，也能是字符串切片;
        
*/
```


### 结构体
```rust
/*
    结构体:
        - attention:
            - 移动: 在实例2中使用实例1的堆可变数据，则会将数据移动到实例2中，其他地方则不能再使用实例1的可变数据; 
                   但移动的是栈的不可变数据，则能使用实例1的数据;
                
            - 克隆: 结构体中与clone/copy trait 同理;
            
        - 结构体中: 所有权与生命周期
            - 结构体的字段是引用类型，必须要指定它的生命周期，rust才能知道字段引用的生命周期;需要这样才能保证内存安全问题;
            
    trait 派生:
        - attention: 在结构体需要打印的时候，会出现编译错误，rust无法自动打印结构体的实例;
        - answer: 使用 #[deriver(Debug)] 来实现;
        
    关联方法（python中的静态方法）
        - 结构体中的普通函数;
        
    结构体方法与关联方法的调用:
        - 方法: object.方法名()，会把实例对象当做第一个参数传给该方法;
        - 关联方法: 结构体名::关联方法名();
        
*/
```
